React Products App

A simple React application built using Vite.

About The Project

This project is a simple products store created to practice the React basics that we learned.

The application contains different components such as Navbar, Hero, Products, ProductCard, and Footer.

Technologies Used:
- React
- Vite
- JavaScript
- Bootstrap
- CSS

React Concepts Used:
- Components
- Props
- useState
- Events
- map()

Features:
- Display products in cards
- Add products to cart
- Remove products from cart
- Responsive design using Bootstrap
- Reusable ProductCard component

Project Structure:
